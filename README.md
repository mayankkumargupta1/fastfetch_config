# Fastfetch Configuration

Personal [Fastfetch](https://github.com/fastfetch-cli/fastfetch) configuration with custom Kitty image logo and styled system information modules.

## Structure

```
~/.config/fastfetch/
├── config.jsonc
├── logo/
│   └── softshell_icon.png
└── README.md
```

## Manual Installation

```bash
git clone git@github.com:mayankkumargupta1/fastfetch_config.git ~/.config/fastfetch
```
